# A/B 비교 2차: 이전 첫 화면(A) 대 투시 렌즈 첫 화면(B) (2026-11-13)

시제품 자동 측정입니다. 사람을 대상으로 한 실험이 아닙니다. 두 안을 실제로 띄워 놓고 같은 과제를 스크립트(`tools/ab2.js`, Playwright, 1600×720)로 수행해 누른 횟수와 시간을 쟀습니다. 두 안 모두 같은 부품 데이터를 씁니다. A는 11월 13일 오전의 화면 구조(v9), B는 지금 화면입니다.

| 과제 | A | B |
|---|---|---|
| 손으로만 오른쪽 헤드램프 품번 보기 | 4번 누름 | 2번 누름 (차 사진의 헤드램프를 누르고, 오른쪽을 고름) |
| 검색으로 같은 품번 보기 (글자 입력 제외) | 2번 누름 | 1번 누름 (첫 화면에 검색창) |
| 점화 플러그 한 대분 4개 담기 | 4번 누름, 몇 개 필요한지 안내 없음 | 1번 누름, '4기통 한 대분' 안내 있음 |
| 검색 결과에서 품번만 저장 | 2번 누름 | 1번 누름 |
| 주문한 뒤 첫 화면 | 진행 상황 표시 없음, 장바구니에 3개 남음 | 진행 중 카드와 부품 주문함 표시, 장바구니 비워짐 |
| 구역 탭을 눌러 구역 화면이 뜰 때까지 (5회 중앙값, 측정 도구 지연 포함) | 245ms | 356ms |

구역 진입 시간은 B가 더 깁니다. 차 사진이 투시 그림으로 바뀌며 들어가는 전환이 있기 때문입니다. 처음 잰 값은 528ms였고, 전환을 줄여 356ms로 맞췄습니다. 누른 직후 화면이 반응을 시작하는 것은 두 안 모두 같습니다.

한계: 누른 횟수와 시간만 잰 것이라 '알아보기 쉬운가'는 재지 못했습니다. 헤드램프가 엔진오일 렌즈에 가려 있을 때는 렌즈 바깥쪽(범퍼 쪽)을 눌러야 헤드램프로 갑니다.
