# 핏스톱 용어 정리 (2026-11-13)

앱 화면, 음성 안내, 영상 자막, 신청서에 같은 말을 씁니다.

## 규칙

1. **부품 이름은 순정 부품 정식 명칭을 앞에 둔다.** 현장 말은 검색에서 모두 통하게 하고(미미, 쇼바, 활대, 드레인 볼트, 라이닝, 밧데리, 깜빡이 등), 정식 명칭이 낯선 부품만 괄호로 함께 적는다. 예: 마운트(미미), 쇼크업소버 (쇼바), 스테빌라이저 링크 (활대 링크).
2. **바꾸는 일은 '교체'로 쓴다.** '교환'은 작업 이름 '엔진오일 교환'에만 쓴다. (교체 주기, 이전 교체, 다음 교체, 와셔 교체, 필터 교체)
3. **상태는 네 가지 말만 쓴다.**
   - 경고: 차가 경고등을 켠 것
   - 교체 필요: 교체 주기(거리 또는 기간)를 넘긴 것
   - 곧 교체: 주기의 80%를 넘긴 것
   - 양호: 그 밖
4. **사는 일은 '주문', 부품 번호는 '품번'**으로만 쓴다. (구매, 부품번호, 파트넘버는 쓰지 않음)
5. **직접 하는 정비는 '셀프 교체', 맡기는 것은 '정비소 교체 권장'**으로만 쓴다.
6. 안내 문구는 '~하세요', '~됩니다'로 끝내고, 그림 위 짧은 표시는 명사형(풀기, 교체, 넣기)으로 맞춘다.
7. 한자어·업계 말은 쉬운 말로 바꾼다. (도래, 지참, 입고, 전장, 공조, 트림, 윤활)

## 그대로 둔 말과 이유

- 마운트(미미), 한 대분, 공임 정비, 품번, 경유지: 정비 현장과 내비게이션에서 실제로 쓰는 말입니다.
- 흡기, 냉각, 점화, 벨트, 서스펜션: 정비소 견적서에 그대로 나오는 묶음 이름이라 유지했습니다.
- 엔진오일 교환: 작업 이름으로 굳은 말입니다.
