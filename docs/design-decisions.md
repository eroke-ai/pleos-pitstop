# 핏스톱 화면 설계 결정 (개발 전 사전 조사, 2026-11-13)

조사 범위는 개발 결정에 바로 쓰이는 네 가지로 한정했습니다.

## 1. 차량 화면 설계 기준과 운전 중 조작 제한
참고: Google Android for Cars 디자인 가이드(Design for Driving), AAOS CarUxRestrictions, NHTSA 운전자 주의분산 가이드라인(한 번 보기 2초, 과업 전체 12초 이내), Pleos 앱 카테고리별 주행 중 허용 기준.

| 결정 | 이유 |
|---|---|
| 부품 찾기·주문·이력 화면은 **P단에서만** 연다. 기어가 P가 아니면 즉시 "주행 중" 화면으로 바꾼다. | CarUxRestrictions, Pleos 심사. 주문·검색은 주행 중 허용 기능이 아님. |
| 주행 중 화면은 **속도 + 큰 음성 버튼 하나**만. 증상 기록은 버튼 1회(또는 음성)로 끝나고 결과는 2초 안에 읽히는 카드 한 장. | 한 번 보기 2초 원칙. 목록·입력 없음. |
| 누를 수 있는 요소는 보이는 크기와 별개로 **최소 56px 터치 영역**(1600×720 기준, 실제 화면에서 약 76dp 이상). | Android for Cars 최소 터치 76dp. |
| 주행 중 글자는 24px 이상, 주차 중 본문 15px 이상, 보조 글자 13px 이상. | 시안 가독성 유지 + 차량 기준. |
| 어두운 화면만 사용, 본문 대비 4.5:1 이상. 주황(행동)·빨강(경고)·초록(양호) 세 색 의미 고정. | 야간 눈부심, 색 의미 일관성. |
| 음성 안내는 주차 순간 1회, 음악은 끄지 않고 소리만 줄인다(덕킹). | 운전 방해 최소화. |

## 2. Pleos Connect 화면·앱 기준
- 시안은 1600×720 가로 화면 기준. 실제 기기 해상도가 달라도 **비율을 유지한 채 확대·축소**해 같은 배치를 보장한다.
- 승인된 상태 조회 권한(CAR_*), 차속, 마이크 권한만 쓴다. 차량 제어·PRIVATE 권한은 쓰지 않는다.
- 차대번호는 동의 후 CarInfo로 읽고, 화면에는 가운데를 가린다(KMH········1234).

## 3. 부품 찾기 흐름 벤치마킹
| 서비스 | 배운 점 | 핏스톱 반영 |
|---|---|---|
| 현대모비스 부품 정보(WPC 방식) | 차대번호 → 계통 → 부품 그림 → 번호 → 품번. 정확하지만 계통 이름을 알아야 함 | 같은 순서를 쓰되 계통 대신 **차 그림 위 위치**로 들어간다(차 → 구역 → 계통 → 부품 그림) |
| 해외 부품몰(연식·차종 선택 후 카테고리) | "내 차에 맞음" 표시가 구매 불안을 줄임 | 모든 부품에 **✔ 내 차 일치** 배지 |
| 대형 쇼핑몰 차량 등록 기능 | 차를 한 번 등록하면 이후 맞는 부품만 노출 | 차대번호 1회 등록 후 내 차 품번만 표시 |
| 정비 앱의 작업 단위 메뉴 | 초보는 부품보다 작업(오일 교환)으로 찾음 | **자주 하는 작업** 바로가기 + 작업 단위 세트 |
| 검색 | 일상어와 공식 품명이 다름(깜빡이 ↔ 방향지시등) | **일상어 사전**으로 바꿔 찾고 "‘깜빡이’ → 방향지시등"을 보여 준다 |

## 4. 반응 속도
| 결정 | 목표 |
|---|---|
| 모든 이미지·글꼴·부품 데이터는 앱 안에 넣는다(네트워크 없이 동작). 이미지는 WebP로 줄임(총 0.7MB). | 첫 화면 1초 안 |
| 앱 시작 시 이미지 미리 불러오기, 화면 전환은 0.2초 이내 애니메이션 | 누름 → 반응 0.1초 |
| 검색은 기기 안 색인으로 글자 입력마다 즉시 결과 | 결과 0.05초 |
| 흐림(blur) 효과는 에뮬레이터에서 느리면 단색 반투명으로 자동 대체 | 끊김 없음 |

## 구현 방식
- 화면: 시안 HTML/CSS를 그대로 살린 앱 내 웹 화면(WebView, 오프라인) — 시안과 같은 디자인을 3일 안에 구현하기 위한 선택.
- 차량 연결: Kotlin(Pleos Vehicle SDK, NaviHelper, TTS/STT)이 차량 값을 웹 화면에 실시간으로 보낸다.
- 시연: 에뮬레이터에 없는 신호(소모품 경고, 경유지 도착)는 숨김 시연 패널로 같은 이벤트를 발생시킨다.
