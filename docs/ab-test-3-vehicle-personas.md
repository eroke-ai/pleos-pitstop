# A/B 비교 3차: Pleos Connect 적용 차종별 운전자 조건 (2026-11-13)

시제품 자동 측정입니다. 사람을 대상으로 한 실험이 아닙니다. Pleos Connect가 들어간 세 차종의 구매층을 '조건'으로 세우고, 이전 화면(A, 11월 13일 오전 구조)과 지금 화면(B)에 같은 과제를 스크립트(`tools/persona2.js`)로 시켜 누른 횟수, 빗나간 횟수, 버튼과 글자 크기를 쟀습니다.

화면에 나오는 차와 부품은 두 안 모두 그랜저 예시 데이터입니다. 차종에 따라 바꾼 것은 운전자 조건(쉬운 보기, 누를 때 20px 빗나감)과 화면 크기뿐입니다. 아반떼·투싼용 부품 데이터와 차 그림은 만들지 않았습니다.

## 읽는 법
- 7개 조건 21개 과제를 지금 화면은 모두 해냈습니다. 이전 화면은 '1만 원 이하만 골라 보기' 기능이 없어 20개만 해냈습니다. 지금 화면이 더 적게 누른 과제는 6개, 같은 과제는 14개, 더 많이 누른 과제는 없습니다.
- 지금 화면이 진 항목: '지금 할 일' 버튼은 이전 화면이 더 큽니다(1600×720에서 155px 대 64px). 지금 화면도 56px 기준은 넘습니다.
- 1차 측정에서 드러나 고친 것: 부품 화면의 수량·주문 버튼이 44px이었습니다. 56px 이상으로 키웠습니다. 작은 화면에서 14px 글자가 11.2px로 줄어 12px 기준 아래였습니다. 가장 작은 글자를 15px로 올려 12px가 되게 했습니다.
- 남은 한계: 16:9 화면에서는 위아래에 빈 띠가 생겨 화면의 80%만 씁니다(두 안 같음). 차종별 부품 데이터와 차 그림은 그랜저뿐입니다. 누른 횟수와 크기만 잰 것이라 '알아보기 쉬운가'는 재지 못했습니다.
